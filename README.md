# Veritas — умный подбор event-подрядчиков

Streamlit-приложение для хакатона **HackAlem AI**: жёсткая фильтрация подрядчиков по городу, категории, дате, формату, бюджету (и опционально языку/длительности) + фактные объяснения через OpenAI API.

## Запуск (2 команды)

```bash
pip install -r requirements.txt
streamlit run app.py
```

Опционально задайте ключ OpenAI:

```bash
# Windows PowerShell
$env:OPENAI_API_KEY="sk-..."
streamlit run app.py
```

Ключ также можно ввести в sidebar приложения.

## Данные

Файл `hackathon-dataset-anonymized.csv` (также поддерживается имя с пробелом перед `.csv`).

Колонки: `id`, `anon_name`, `categories`, `city`, `price_from_kzt`, `event_formats`, `languages`, `max_hours`, `busy_dates`, `description`, `synthetic`.

Списки (`categories`, `event_formats`, `languages`, `busy_dates`) парсятся из строк с разделителями `,` / `;` / `|` (и из Python-list строк).

## Архитектура

```
[UI Streamlit]
   ├─ демо-кнопки жюри (3 сценария)
   ├─ sidebar: фильтры + OpenAI API Key
   └─ результаты: исходы A / B / V
        │
[Жёсткий фильтр — «вышибала»]
   1. city == выбранный город
   2. category ∈ categories
   3. дата ∉ busy_dates
   4. price_from_kzt ≤ бюджет
   5. format ∈ event_formats
   6. язык ∈ languages (если задан)
   7. max_hours ≥ длительность (если задана и max_hours не пусто)
        │
[Ранжирование топ-3]
   детерминированно: price_from_kzt ↑, затем id
        │
[Объяснения]
   OpenAI gpt-4o-mini, temperature=0
   или факт-заглушка (цена, экономия, языки, цитата из description)
```

### Три обязательных исхода

| Исход | Условие | UI |
|-------|---------|----|
| **A** | 1–N прошедших фильтр | Карточки топ-3 + AI/факт объяснения; если &lt; 3 — почему выдача неполная |
| **B** | 0 специалистов категории в городе | `В городе {город} нет специалистов в категории {категория}` |
| **V** | В городе есть специалисты, но все отсеялись | Детальный текстовый расклад причин |

## Демо-сценарии для жюри

1. **Плотная категория** — Алматы, Ведущий, 15.10.2026, корпоратив, 1 000 000 ₸ → топ-3.
2. **Редкая категория** — Астана, Флорист, 05.11.2026, свадьба, 350 000 ₸ → 1 кандидат (Хаку) + пояснение, почему меньше 3.
3. **Запрос без результата** — Алматы, Ведущий, 25.12.2026, той, 300 000 ₸ → исход V (занятость декабря / бюджет / формат).

## Стек

- `pandas` — загрузка и фильтрация CSV
