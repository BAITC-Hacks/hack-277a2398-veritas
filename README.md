# Veritas — умный подбор event-подрядчиков

Прототип для HackAlem AI, кейс #79-lite. Приложение отбирает event-подрядчиков из CSV и показывает объяснения, привязанные к фактам профиля.

## Запуск за 2 команды

```bash
pip install -r requirements.txt
streamlit run app.py
```

Ключ OpenAI можно указать в боковой панели или задать переменную окружения `OPENAI_API_KEY`. Без ключа приложение строит объяснения из цены, экономии, языков и описания подрядчика.

## Архитектура

```text
CSV (csv.DictReader; только стандартная библиотека)
  → разбор категорий, форматов, языков и busy_dates
  → жёсткая фильтрация по городу, категории, доступности, бюджету,
    формату, языку и длительности
  → детерминированный скоринг и топ-3
  → персональное объяснение через OpenAI gpt-4o
    (или локальное объяснение по фактам без API)
```

Поля-списки принимают запятые, точки с запятой, `|` и строки Python-списков. Для ранжирования используются фиксированные веса: совпадение языка (если выбран фильтр), релевантность описания формату и близость цены к бюджету; равенства разрешаются по `id` и имени.

OpenAI получает профиль кандидата и конкретные параметры заказа. Промпт просит найти индивидуальные зацепки из описания, связать их с форматом события, не выдумывать достижения и привести цену, экономию и требуемый язык. Температура равна 0.

## Исходы поиска

- **A — кандидаты найдены:** выводит до трёх лучших карточек. Если результатов меньше трёх, объясняет размер выдачи и причины отсева.
- **B — категории нет в городе:** выводит предупреждение «В городе {город} нет специалистов в категории {категория}».
- **V — все кандидаты отсеяны:** показывает число специалистов и распределение причин отказа.

## Демо для жюри

1. **Плотная категория:** Алматы, ведущий, 15.10.2026, корпоратив, 1 000 000 ₸ — демонстрация детерминированного топ-3.
2. **Редкая категория:** Астана, флорист, 05.11.2026, свадьба, 350 000 ₸ — ожидается один кандидат «Хаку» и пояснение, почему выдача неполная.
3. **Запрос без результата:** Алматы, ведущий, 25.12.2026, той, 300 000 ₸ — детальный отчёт о занятости и/или превышении бюджета.

Даты ограничены периодом с 23.09.2026 по 31.12.2026. Датасет `hackathon-dataset-anonymized.csv` должен лежать рядом с `app.py` (поддерживается также имя с пробелом перед `.csv`).

## Зависимости

Только Streamlit и OpenAI SDK. CSV разбирается встроенным модулем Python `csv`; pandas и numpy не используются.
