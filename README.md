# Veritas — умный подбор event-подрядчиков

Прототип для хакатона по треку «Креативные индустрии», кейс «Умный подбор подрядчиков» (владелец задачи — Firebird).

Заказчик задаёт город, дату, формат события, категорию и бюджет, а сервис отбирает из готового каталога до трёх подходящих подрядчиков. В карточке каждого кандидата показаны цена, экономия относительно бюджета и объяснение на основе данных его профиля.

## Возможности

- Фильтрация по городу, категории, занятости на выбранную дату, бюджету и формату мероприятия.
- Необязательные фильтры по языку и длительности (максимальному количеству часов в профиле).
- Детерминированное ранжирование прошедших фильтры кандидатов и выдача не более трёх карточек.
- Объяснение для каждой карточки: из профиля берётся релевантный фактический фрагмент, указываются цена, экономия, языки и форматы. В режиме GPT-4o объяснение формирует OpenAI; автономный режим использует локальный генератор.
- При сбое API, сети или лимита автоматом включается локальное объяснение. В карточке оно помечено «Объяснение: Детерминированный Fallback (Offline)».
- Отдельные сообщения, если в городе нет такой категории, если условиям не соответствует ни один специалист или если нашлось меньше трёх кандидатов.
- Три встроенных демо-сценария для быстрой демонстрации.
- Три режима генерации объяснений в боковой панели: демо-ключ команды, собственный OpenAI API Key и автономный режим без API.

## Состав файлов

Положите приложение, `requirements.txt` и CSV в одну папку. Приложение ищет датасет рядом с собой под одним из двух имён:

- `hackathon-dataset-anonymized.csv`
- `hackathon-dataset-anonymized .csv` (с пробелом перед `.csv`)

```text
project/
├── app.py
├── requirements.txt
└── hackathon-dataset-anonymized .csv
```

## Запуск

Нужен Python с `pip`. Из папки проекта выполните:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Для режима команды задайте `OPENAI_API_KEY` в окружении или Streamlit Secrets. Также ключ можно ввести в боковой панели в режиме «Ввести свой OpenAI API Key». Не храните ключи в исходном коде или Git. Без API поиск и объяснения по фактам профиля работают локально. При подключённом ключе приложение обращается к OpenAI API за объяснениями GPT-4o. В `requirements.txt` требуется только Streamlit: запрос к OpenAI отправляется стандартным модулем Python `urllib`, OpenAI SDK не нужен.

## Как работает подбор

1. Приложение читает CSV стандартным модулем `csv.DictReader` и проверяет наличие обязательных колонок.
2. Сначала выбираются подрядчики с точным совпадением города и категории.
3. Затем кандидаты отсекаются, если заняты в выбранную дату, цена выше бюджета, формат не поддерживается, не совпадает выбранный язык или профиль не покрывает требуемую длительность. Если `max_hours` в профиле пуст, кандидат по длительности не исключается.
4. Прошедшие фильтры кандидаты сортируются по детерминированному баллу. В текущей реализации учитываются языковое покрытие профиля — 45%, релевантность описания формату события — 35% и близость цены к бюджету — 20%. При равном балле порядок определяется ID и именем.
5. Пользователю показываются первые три кандидата и отдельное объяснение для каждого.

Поля со списками в CSV поддерживают запятые, точки с запятой, символ `|` и строковое представление Python-списка. Даты поиска ограничены диапазоном с 23 сентября по 31 декабря 2026 года.

## Демо-сценарии

- **Плотная категория:** Алматы, ведущий, 15.10.2026, корпоратив, 1 000 000 ₸ — демонстрация ранжирования и топ-3.
- **Редкая категория:** Астана, флорист, 05.11.2026, свадьба, 350 000 ₸ — демонстрация неполной выдачи, если найдено меньше трёх кандидатов.
- **Без результата:** Алматы, ведущий, 25.12.2026, той, 300 000 ₸ — демонстрация причин, по которым кандидаты не прошли фильтры.

## Архитектура отказоустойчивости (Graceful Degradation)

Объяснения можно получать от GPT-4o, а при выборе автономного режима, отсутствии ключа или ошибке API приложение использует локальный детерминированный генератор. Он не отправляет внешние запросы: рассчитывает экономию как разницу между бюджетом и ценой, показывает языки и форматы профиля и выбирает первое подходящее предложение либо факт из `description`. Результат не зависит от сети и воспроизводится для тех же данных и параметров.

В демо-режиме командный ключ берётся из переменной окружения `OPENAI_API_KEY` или Streamlit Secrets. Если он не настроен, приложение продолжает работу через offline fallback. Промо-баланс аккаунта приложению недоступен для проверки; интерфейс сообщает, когда командный ключ подключён.

## Данные

Приложение рассчитано на CSV с полями `id`, `anon_name`, `categories`, `city`, `price_from_kzt`, `event_formats`, `languages`, `max_hours`, `busy_dates` и `description`. В переданном датасете 66 записей. Дополнительные поля датасета не используются для подбора.

Результаты зависят от полноты каталога и указанных в профилях данных. Балл ранжирования — правило сортировки прототипа, а не оценка качества подрядчика. Объяснения строятся на информации профиля и не подтверждают её независимо.
